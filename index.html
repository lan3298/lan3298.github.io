从零搭建 WordPress 站点

适配系统：Debian 13 | 环境：Nginx + PHP8.2 + MariaDB

一、环境准备

1. 系统更新

apt update && apt upgrade -y

2. 安装核心依赖

apt install -y nginx php8.2 php8.2-fpm php8.2-mysqli mariadb-server wget ufw
说明：安装包包含 Nginx（web服务器）、PHP8.2（运行环境）、mysqli扩展（数据库连接）、MariaDB（数据库）、wget（下载工具）、ufw（防火墙）

二、MariaDB 安全配置与数据库创建

1. 初始化 MariaDB 安全设置

mysql_secure_installation

按提示依次操作：

  • 设置 root 密码（例：lanshan888）
  • 移除匿名用户：Y
  • 禁止 root 远程登录：Y
  • 删除测试数据库：Y
  • 刷新权限：Y

2. 创建 WordPress 数据库和用户

mariadb -u root -p

输入 root 密码后，执行以下 SQL 命令：

-- 创建数据库（UTF8MB4编码兼容所有字符）
CREATE DATABASE wordpress DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建专属用户（密码可自定义）
CREATE USER 'wpuser'@'localhost' IDENTIFIED BY 'lanshan888';

-- 赋予用户数据库全部权限
GRANT ALL PRIVILEGES ON wordpress.* TO 'wpuser'@'localhost';

-- 刷新权限表
FLUSH PRIVILEGES;

-- 退出数据库
EXIT;

三、下载并配置 WordPress

1. 创建网站根目录并下载 WP

# 创建目录并进入
mkdir -p /var/www/html && cd /var/www/html

# 下载WordPress中文包（国内源，速度快）
wget https://cn.wordpress.org/wordpress-6.6.1-zh_CN.tar.gz

# 解压并整理文件
tar -zxvf wordpress-6.6.1-zh_CN.tar.gz
mv wordpress/* ./
rm -rf wordpress wordpress-6.6.1-zh_CN.tar.gz

# 设置权限（让Nginx/PHP可读写）
chown -R www-data:www-data /var/www/html
chmod -R 755 /var/www/html
若 wget 提示 "command not found"，先执行：apt install -y wget

四、配置 Nginx 支持 PHP + 域名

1. 备份原有配置

cp /etc/nginx/sites-available/default /etc/nginx/sites-available/default.backup

2. 编辑 Nginx 配置

vi /etc/nginx/sites-available/default

删除原有内容，粘贴以下配置（替换 tv.520680.xyz 为你的域名）：

server {
    listen 8080 default_server;
    listen [::]:8080 default_server;
    server_name tv.520680.xyz;

    root /var/www/html;
    index index.php index.html index.htm;

    # WP伪静态规则（必备）
    location / {
        try_files $uri $uri/ /index.php$is_args$args;
    }

    # PHP8.2解析配置
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # 安全配置：禁止访问敏感文件
    location ~ /\.ht {
        deny all;
    }
    location ~ wp-config.php {
        deny all;
    }
}

保存退出：按 Esc → 输入 :wq → 回车

3. 验证配置并重启 Nginx

# 检查配置语法是否正确
nginx -t

# 重启Nginx使配置生效
systemctl reload nginx
若提示配置错误，检查代码是否有拼写错误，尤其是分号、大括号是否闭合

五、防火墙放行端口

# 放行8080端口（WP访问端口）
ufw allow 8080/tcp comment "WP 8080 port"

# 启用防火墙（首次执行需输入 Y 确认）
ufw enable

# 查看防火墙状态（确认8080端口已放行）
ufw status
若系统无ufw，先执行：apt install -y ufw；也可跳过（默认无防火墙）

六、完成 WordPress 安装

1. 访问安装向导

浏览器打开：http://你的域名:8080（例：http://tv.520680.xyz:8080）

2. 填写数据库信息

配置项 填写内容
数据库名 wordpress
用户名 wpuser
密码 你设置的密码（例：lanshan888）
数据库主机 localhost
表前缀 wp_（默认）

3. 完成站点配置

按提示设置：站点标题、管理员账号/密码、邮箱 → 点击「安装 WordPress」即可完成

七、常见问题排查

1. 404 Not Found 错误

  • 检查目录：ls -la /var/www/html（确认有wp-admin、index.php等文件）
  • 验证Nginx根路径：cat /etc/nginx/sites-available/default | grep root
  • 重启Nginx：systemctl reload nginx

2. PHP 缺少 mysqli 扩展

apt install -y php8.2-mysqli
systemctl restart php8.2-fpm

3. 502 Bad Gateway 错误

  • 检查PHP-FPM状态：systemctl status php8.2-fpm
  • 重启PHP-FPM：systemctl restart php8.2-fpm
  • 确认fastcgi_pass路径：/run/php/php8.2-fpm.sock

八、安全建议

  • 删除冗余文件：rm /var/www/html/wp-config-sample.php
  • 定期更新：WordPress核心、主题、插件
  • 强化密码：禁用弱密码，开启后台登录验证码
  • 定期备份：数据库（mysqldump -u wpuser -p wordpress > wp_backup.sql）+ 网站文件
适配性：其他Debian/Ubuntu版本仅需调整PHP版本号（如PHP8.1替换为php8.1-fpm/php8.1-mysqli）
